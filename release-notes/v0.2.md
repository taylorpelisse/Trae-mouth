### 新增

- 新增管理端一键更新能力。系统可从 GitHub Release 获取新版本信息，展示版本说明，并在校验安装包后自动完成文件替换与服务重启。
- 新增更新检查机制。服务运行时每天 00:00 自动检查一次，也可在设置页手动触发检查。
- 仪表盘服务版本旁新增更新提示。发现新版本时，可直接进入设置页处理。
- 设置页新增账号失败换号次数、首字超时、工具结果长度、历史上下文长度和历史消息数量等限制项。
- 行为开关新增模型目录预热选项。

### 优化

- 设置页改为即时自动保存，移除右上角保存按钮。开关即时生效，数值与文本在停止输入后自动提交。
- 并发与限流区域补充总并发上限展示，便于确认账号池整体处理能力。
- 管理端仪表盘与日志页调整为 0.5 秒刷新，提升运行状态与调用记录的实时性。
- 默认参数调整：单账号并发 3、账号冷却 120 秒、首字超时 60 秒、失败换号 2 次。
- 底部导航栏增强阴影，改善浮层层级。
- 更新检查结果缓存 24 小时，避免频繁访问 GitHub。

### 修复

- 修复设置项保存后刷新页面显示为空的问题。
- 修复新增设置项未包含在配置读取响应中的问题。
- 修复切换管理页面时出现全屏“加载中”的问题。
- 修复顶部 GitHub 仓库与反馈入口地址。
- 修复登录助手说明中的本地路径。
