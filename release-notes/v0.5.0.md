### 新增
- 新增真实账单回查：每个请求结束后用上游账单接口核对本次的缓存命中与积分消耗。此前只看流式事件里的计数，而上游从 10 月底起把缓存命中报成 0，账单里却是真实值，导致面板上的成本完全失真。
- 新增模型倍率列：从目录响应里解析出每个模型的计费倍率（0.01 到 1.91），模型页可以直观看出哪个模型贵。
- 新增账号轮转：对话空闲超过 30 分钟、或已消耗某账号两成余额时，下一次请求会换到别的账号。连续任务中途不换号，工具调用链不会断。

### 优化
- 缓存命中率只统计账单查到的请求。查不到时计数记 0，混进分母会把命中率算成假的低值；现在这类行标为未知并单独计数。
- 收支图的支出改为逐请求账单累加。原先按每日余额差推算，余额受签到、充值、并发影响，算不准单日消耗。
- 趋势图的失败数改为红色面积填充，与成功数同轴显示。
- 模型页列宽按内容重排：模型 ID 与推理档位加宽，三个勾选列与徽标收窄。
- 日志页删除上下文列（同一模型每行都是同一个值），新增缓存命中率列。
- 签到设备号改用不同的推导方式与机型标识，功能等价。

### 修复
- 修复上游会话 id 复用导致账单只能拿到累计值的问题。账单按会话结算，一个会话里跑多个请求时算不出单次成本；现在每次请求用独立的上游会话 id，对外的会话 id 仍按对话保持稳定。
- 修复长对话（50 万 token 以上）的账单查不到、积分记成 0 的问题。
- 修复指标接口在无数据日期上报错的问题。
